# Nicholas Buhmann-Holmes — academic website

This is a deliberately simple static website designed for GitHub Pages.

## Files

- `index.html` — all website content
- `style.css` — visual design
- `images/Billede.jpg` — profile photo
- `cv.pdf` — add your CV here when ready

## Before publishing

In `index.html`, replace:

- `YOUR-EMAIL@lu.se`
- `YOUR-GOOGLE-SCHOLAR-URL`
- `YOUR-ORCID-URL`
- `YOUR-BLUESKY-URL`

You can also replace the placeholder text in Research & Publications, Working Papers,
Teaching, and Datasets with your actual material.

No build process or software is required. GitHub Pages can serve these files directly.
